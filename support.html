FAQ

Frequently asked questions

How do I get the Windows installer?

Request access from the Download page or email support@rxpulsecs.com. Installers are shared only through the official channel. Verify the file name and checksum before running.

Why does Windows SmartScreen show a warning?

Code signing is still pending. The warning can appear for new publishers. Confirm the official file name and checksum from support, then choose More info → Run anyway only if the file matches.

How does account creation work?

Open the Windows app, enter your email, confirm the six-digit code from inbox/spam, create a password, then submit BMDC, degree, specialty, and chamber details for admin review.

When can I use clinical features?

After administrator approval of your professional profile. Until then, clinical access stays locked.

Does RxPulse work offline?

After a prior login, chamber work can continue on weak or offline internet. Sync when connectivity returns. Confirm Cloud Sync Complete before uninstall or sign-out if you have unsynced data.

How should I contact support?

Email support@rxpulsecs.com from your registered address. Include doctor name, Windows version, app version, and a short problem description. Hide patient-identifying details in any screenshots.
