RxPulse desktop beta access and safe install guidance.

The Windows desktop beta is distributed through controlled access for approved doctors. The installer link is not public; request access from your registered email.

Windows Desktop Beta

RxPulse Clinician Suite 1.2.0

The file name should be RxPulse-Clinician-Suite-1.2.0-Setup-x64.exe. When a verified build is released, the official SHA-256 checksum will be published on this page or included as SHA256SUMS.txt with the support/download package. Do not run any installer without a checksum.

Checksum

Verify the installer

Current verified SHA-256: pending until a verified installer is published. If this value is pending, do not run the installer; request the checksum from support.

  • Get the installer only through the official RxPulse support/download channel.
  • Match the exact SHA-256 published on this page or the SHA256SUMS.txt included with the support/download package.
  • If the checksum does not match, do not run the installer; contact support.
SmartScreen

Windows SmartScreen may appear

The current beta installer may be unsigned, so Windows SmartScreen may show a warning. Verify the file name and SHA-256 checksum before proceeding, then follow the install guide.

Windows install guide
Install notes

Before installing

  • Internet is required for first login and cloud sync.
  • After prior login, chamber work can continue during weak internet.
  • Sync before uninstalling, reinstalling, or switching devices.
  • Use one doctor account per Windows user/device workspace.
Desktop required

Use the Windows app for clinical work

Patient records, prescriptions, synchronization, and other clinical features are not available through an ordinary web browser. Approved doctors must install the RxPulse Windows desktop application and sign in there.
