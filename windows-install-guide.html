Windows setup guide

Set up the RxPulse desktop beta safely.

Get the setup file only from the official channel and confirm with support if anything looks unclear.

Step 1

Confirm the official source

  • Use only the official RxPulse support/download channel.
  • File name: RxPulse-Clinician-Suite-1.2.0-Setup-x64.exe
  • Contact support if source or version is unclear.
Step 2

Security check

  • Match the SHA-256 checksum.
  • If it does not match, do not run setup.
  • If a security warning appears, stop until confirmed.
Step 3

Complete setup and open RxPulse

  • Run setup to completion.
  • Open RxPulse from Start Menu or shortcut.
  • Internet is required for first login and cloud sync.
Data safety

Before update or reinstall

  • Confirm Cloud Sync Complete.
  • One doctor account per Windows workspace.
  • Hide patient identity in support screenshots.
