Windows setup guide

Set up the RxPulse desktop beta safely.

This guide is for approved doctors. The desktop beta is provided through controlled, support-assisted access. Get the setup file only from the official RxPulse support/download channel and confirm with support if anything looks unclear.

Step 1

Confirm the official source

  • Use only the official RxPulse support/download channel for the setup file.
  • File name should be: RxPulse-Clinician-Suite-1.2.0-Setup-x64.exe
  • Contact support if the source, file name, or version is unclear.
Step 2

Complete the security check

  • Match the SHA-256 value with the value provided by support or SHA256SUMS.txt.
  • If the checksum does not match, do not run the setup file; contact support.
  • If a security warning appears, do not proceed until the file details are confirmed.
Step 3

Complete setup and open RxPulse

  • Start the setup process after the security check is complete.
  • After setup, open RxPulse from the Start Menu or desktop shortcut.
  • Internet is required for first login and cloud sync.
Data safety

Before update or reinstall

  • Before updating or reinstalling, confirm Cloud Sync Complete.
  • Use one doctor account per Windows user/device workspace.
  • Hide patient identity before sending screenshots or support files.
  • For setup or login problems, email support@rxpulsecs.com with Windows version, app version, and screenshot.

Short setup checklist

  1. Get the setup file from the official RxPulse source
  2. Verify the file name and SHA-256 checksum
  3. If there is a warning, mismatch, or doubt, confirm with support

Real Windows screenshots will be added before wider public release. For the pilot stage, use support-assisted setup.
