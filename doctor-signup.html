Desktop account setup

Create your doctor account in the RxPulse Windows app

The public website no longer collects doctor signup emails, verification tokens, or signup passwords. Secure account creation now happens only inside the installed RxPulse Windows application.

1Download and install RxPulse

Open the Windows app to start account creation.

2Use email and a six-digit code

Enter your email in the desktop app, type the six-digit email code in the app, then create your password.

3Professional profile approval is required

Complete your professional profile with BMDC, degree, specialty, and chamber information, then submit it for administrator approval.

Browser signup retired

This compatibility page does not show a signup form and does not make any signup API call. Password recovery remains available on the website.

Windows app required

Download RxPulse to get started

Doctor account creation happens entirely inside the RxPulse Windows desktop application. Get the installer from the download page, or contact support if you need help.
