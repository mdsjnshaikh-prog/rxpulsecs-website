How it works

How doctors start using the RxPulse Windows desktop application in simple steps.

A doctor downloads and opens the Windows desktop application, enters an email, confirms the six-digit email code, creates a password, and submits professional details for review. RxPulse can be used after administrator approval. The clinical workspace is not available through an ordinary web browser.

1

Download and install RxPulse

Use the download page to request Windows desktop access and follow the safe installation guidance. Prospective doctors may request access before creating an account.

2

Open the app and enter email

Open the RxPulse Windows app and enter the email you will use for your account.

3

Enter six-digit code

Enter the six-digit code sent to your email inside the Windows app. Check both inbox and spam folder.

4

Create password

After the email code is accepted, create your password in the Windows app to finish account creation.

5

Sign in and add professional details

Sign in and complete the required BMDC number, professional name, degree, specialty, chamber information, and other details.

6

Submit for administrator approval

Submit the professional profile for review. Clinical access remains unavailable until administrator approval.
