How it works

Start RxPulse in six clear steps.

From downloading the Windows app to administrator approval—each step in brief.

1

Download and install

Get the official Windows installer from the Download page or support channel. Use only the official file; if SmartScreen appears, verify the file name and checksum.

2

Create an account

Sign up with your email inside the Windows app. Account creation happens in the app, not on this website.

3

Verify email code

Confirm your address with the 6-digit code sent by email. If the code does not arrive, check spam or write to support.

4

Complete professional profile

Provide correct BMDC, degree, specialty, and chamber information. Wrong or incomplete details can delay or block approval.

5

Submit for approval

Submit your profile. Clinical access starts after administrator review. Plan and trial details are shown inside the app.

6

Start chamber work

After approval, use patient details, prescriptions, records, and print. Keep internet available for first login and sync.

Remember

Important notes

Where is clinical work?

Only in the Windows app. This website is for information and access guidance.

Support

Write from your registered email to support@rxpulsecs.com—not for clinical emergencies.

Ready to start?

Request beta access or write to support.
