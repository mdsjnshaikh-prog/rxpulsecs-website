How it works

How doctors start using the RxPulse Windows desktop application in simple steps.

A doctor downloads and opens the Windows desktop application, enters an email, confirms the six-digit email code, creates a password, and submits professional details for review. RxPulse can be used after administrator approval. The clinical workspace is not available through an ordinary web browser.

1

Enter email

Use an email you can open now. No password is taken at this step.

2

Enter six-digit code

Enter the six-digit code sent to your email inside the Windows app. Check both inbox and spam folder.

3

Set password

Create your password in the Windows app after the email code is accepted.

4

Get the Windows desktop application

Use the download page for desktop access and safe installation guidance. Clinical work is not available through an ordinary browser.

5

Sign in to the desktop app

Sign in to the RxPulse Windows desktop application with your new password.

6

Add professional details

Add BMDC number, professional name, degree, specialty, chamber information, and other required details.

7

Send for review

Send the completed information for review. After approval, the doctor can start using the desktop software for chamber work.
